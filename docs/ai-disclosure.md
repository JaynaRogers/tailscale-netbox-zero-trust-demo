# AI assistance disclosure

Generative AI was used as an **assistant** during this take-home project to help draft commands, documentation, architectural descriptions, validation scripts, policy examples, and interview presentation materials.

The candidate performed the live Oracle Cloud setup, Tailscale enrollment, NetBox deployment, troubleshooting, GitHub review/merges, and the reported Windows/macOS connectivity tests. AI-produced configurations and explanations were reviewed against actual command output and observed application behavior. The repository intentionally distinguishes observed results from assumptions and unverified controls.

No claim is made that the code, documentation, diagrams or slides were produced without AI support. The candidate remains accountable for validating design choices and explaining all parts of the project during the technical walkthrough.
